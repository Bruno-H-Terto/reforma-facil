# Regras do projeto
- Ler docs/brainstorm.md e docs/validacao.md antes de alterar escopo.
- Preferir componentes existentes, React Aria, HTML semântico e Tailwind; evitar dependências redundantes e abstrações prematuras.
- Separar dados, apresentação e cálculos; usar Prettier e Oxlint.
- Nunca apresentar hipóteses tributárias como regras legais. Atualizar referências oficiais e data de revisão quando alterar conteúdo.
- Não expor chaves de IA no cliente nem fingir atualização automática.
- Validar build, lint e testes E2E antes de concluir. Registrar limitações e fazer commits pequenos.
