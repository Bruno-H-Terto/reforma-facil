# Ícones do cronograma
Arquivos originais baixados do SVG Repo, coleção Lucide Line Icons, sem modificar o desenho. A cor é aplicada via CSS mask.
- https://www.svgrepo.com/svg/389048/book
- https://www.svgrepo.com/svg/389032/beaker
- https://www.svgrepo.com/svg/389023/banknote
- https://www.svgrepo.com/svg/389013/arrow-left-right
- https://www.svgrepo.com/svg/389019/award

As fichas do SVG Repo exibem CC0 para book, beaker, banknote e award e MIT para arrow-left-right, com atribuição Lucide Contributors. Por precaução, preserva-se também a licença upstream Lucide/Feather, em LICENSE.txt, obtida de https://github.com/lucide-icons/lucide/blob/main/LICENSE.
